## Harness finding (affects every earlier stepped QA)

`Clock.advance` clamps a frame to `MAX_FRAME_DT = 0.1` s (`src/core/clock.ts`). `step(0.125, 1)` or `step(0.25, 1)` therefore advances only 0.1 s while the label
says more. My first flash run (labelled 0.125 steps) showed a 0.5 s blink period for exactly this reason; with `step(dt / k, k)`, k = ceil(dt / 0.1), the period is 0.42.
Use `step(<=0.1, n)` or the `simt` URL parameter (warm-up has no clamp). Worth one line in the visual-qa skill. Owner: qa.
