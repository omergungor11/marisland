## Triangle regression (most important)

W5 went 789,857 to 807,379 (+17.5k) with 46 agents in frame; 17.5k / 46 is about 380 tris per bot, which matches the beacon variants in the shared bot mesh (D-144: 7 variants, 364 tris total, bot mesh 2114 tris vs ~1750 before). Wow shots carry no `fleet` param, so no bot is bound: the unbound beacon slots appear to still be drawn (or counted) for every instance. This is inference from the arithmetic, not read from the draw code. Visually the wow frames are unchanged (no stray gems seen in the contact sheet, W27 night checked).
